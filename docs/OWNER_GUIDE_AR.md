# إدارة موقع جلال

الموقع الحالي: https://galalparts.grok.me/
التعديلات على فرع `netlify-deploy`. فرع `main` هو النسخة السابقة ولا نعدله.

## إضافة قطعة حقيقية

1. افتح `content/products.json` من GitHub على فرع `netlify-deploy`.
2. انسخ كائن `content/templates/product.json` داخل قائمة `products`؛ افصل كل كائن عن التالي بفاصلة.
3. املأ الاسم والوصف والفئة وslug (رابط فريد بحروف إنجليزية صغيرة وشرطات).
4. ارفع الصور إلى `public/parts/` واكتب مسارها مثل `/parts/اسم-الصورة.webp` في `photos`، مع وصف عربي للصورة في `alt`.
5. اترك الكود والماركة والموديلات فارغة إذا لم تتأكد منها. اترك السعر `null` إذا لم يكن موثقًا.
6. اجعل `published` يساوي `true` فقط بعد مراجعة البيانات. الحفظ على GitHub يشغّل نشر Netlify، وتظهر صفحة القطعة وتدخل خريطة الموقع تلقائيًا.

| الحقل              | ماذا تكتب؟                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------- |
| `nameAr`           | اسم القطعة الحقيقي بالعربية                                                               |
| `nameEn`           | اسم إنجليزي اختياري أو نص فارغ                                                            |
| `slug`             | رابط فريد، مثل تسمية القطعة الفعلية بحروف إنجليزية                                        |
| `category`         | `washers` / `fridges` / `heaters` / `stoves`                                              |
| `brand`            | الماركة الموثقة أو نص فارغ                                                                |
| `partCode`         | الكود المكتوب على القطعة أو العبوة، أو نص فارغ                                            |
| `compatibleModels` | قائمة الموديلات المؤكدة فقط، أو `[]`                                                      |
| `description`      | وصف مختصر حقيقي                                                                           |
| `photos`           | قائمة كائنات تحتوي `src` و`alt`، أو `[]`                                                  |
| `availability`     | `available` متاح، `on-request` حسب الطلب، `unavailable` غير متاح، `unknown` يحتاج تأكيدًا |
| `price`            | مبلغ موجب بالجنيه المصري أو `null`؛ لا يُعرض سعر افتراضي                                  |
| `notes`            | ملاحظات الاختلاف بين الإصدارات والتركيب إن وُجدت                                          |
| `relatedParts`     | قائمة slug لقطع موجودة بالفعل أو `[]`                                                     |
| `published`        | `false` مسودة؛ `true` منشور                                                               |

فئات القطع الموجودة أصلًا في `content/catalog.json` أمثلة للاستفسار وليست مخزونًا مؤكدًا. لم تتحول إلى منتجات وهمية.

**البيانات المطلوبة منك لأول دفعة منتجات:** الاسم، نوع الجهاز، وصف وصور حقيقية، حالة التوفر. الماركة والكود والموديلات المتوافقة والسعر تُضاف فقط إذا كانت مؤكدة. عدم وجودها لا يمنع إضافة القطعة، لكن يبقى التأكيد عبر صورة ملصق الجهاز.

## الخدمات والمقالات

- `content/catalog.json`: الخدمات الأربعة وأمثلة الأعطال وفئات القطع.
- `content/articles.json`: المقالات الحالية؛ انسخ بنية مقال موجود مع slug فريد، عنوان، وصف، ملخص، فئة وأقسام.
- أولويات المحتوى: معرفة الموديل، تصوير الملصق، تفسير وظيفة القطعة ومتى تستدعي فنيًا. راجع المحتوى فنيًا قبل نشره؛ لا تكتب قوائم توافق بالتخمين.
- لا تنشر بيانات عنوان العميل أو أرقامًا ظاهرة على الملصق دون حاجة.

## صور الشغل وآراء العملاء

في `content/credibility.json`:

- `workPhotos`: كائن به `src` لمسار الصورة، `alt`، `caption` لوصف العمل، و`permissionGranted`.
- `reviews`: كائن به `name` للاسم المسموح نشره، `quote` للنص الحقيقي، و`permissionGranted`.

تظهر العناصر فقط عندما `permissionGranted: true` بعد موافقة صاحبها. لا تُعرض أقسام فارغة ولا تقييمات نجوم تلقائية. أخفِ العناوين وأرقام العملاء من الصور.

## التواصل والتحليلات

`content/site.json` هو المصدر الوحيد لرقم واتساب والهاتف وفيسبوك ويوتيوب ومناطق الخدمة. الرقم الموجود احتُفظ به كما هو. لا تغيّر `SITE_URL` ولا ملف `public/google7b77a1134d8b36f5.html`.

التحليلات جاهزة كأحداث فقط، ولا ترسل بيانات لأي مزود حاليًا. لتفعيل القياس تحتاج:

- GA4: حساب وموقع قياس وMeasurement ID بصيغة `G-...`.
- Meta: Dataset/Pixel ID الخاص بنشاطك.
- تحديد ما ستفعله عند قبول ورفض الموافقة، وتحديث سياسة الخصوصية قبل تفعيل أي مزود.

لا ترسل مفاتيح API خاصة. المعرفات السابقة عامة، لكن لا يوجد أي معرف مخترع في الكود. راجع `docs/TRACKING.md` للمطور.

## تحقق قبل الحفظ والنشر

```bash
npm ci
npm run validate:content
npm run typecheck
npm test
npm run lint
npm run build
```

Netlify يفحص البيانات قبل البناء. JSON خاطئ، أو صورة محلية مفقودة، أو slug مكرر، أو قطعة مرتبطة غير موجودة يوقف البناء. النسخة المنشورة السابقة تبقى حتى نجاح نشر النسخة الجديدة.
